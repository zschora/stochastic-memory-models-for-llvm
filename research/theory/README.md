For future imports from the research archive, add focused Markdown files with LaTeX math. Include the precise model, assumptions, theorem or conjecture status, proof or derivation, validation scripts, and prior-art references. Do not mark an unaudited asymptotic claim as proved merely because finite tests agree.

Suggested statuses: **Proved**, **Working proof**, **Numerically checked**, **Conjecture**, and **Known prior art**. Mathematical model predictions must never be mislabeled as hardware measurements.
