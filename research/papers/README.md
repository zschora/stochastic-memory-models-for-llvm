# Research papers and manuscripts

This directory is reserved for article-length drafts, mathematical proof audits, independent reviews, literature searches and publication materials. Prefer Markdown with LaTeX math as an editable source; add PDF/LaTeX artifacts alongside it only when needed.

Suggested structure for a new article:

```text
research/papers/<short-slug>/
  manuscript.md     # current full draft
  references.md     # verified primary sources and prior-art comparison
  review.md         # open proof gaps, validation and reviewer decisions
  figures/          # only when needed
```

Create article folders when there is real content, rather than empty placeholders. Use [TEMPLATE.md](TEMPLATE.md).

Publication statuses must be explicit: **Draft/conjectural**, **Internal proof pending review**, **Independently audited**, **Submitted**, **Published**. A polished PDF or a numerical check does not establish mathematical correctness, novelty or peer review.
