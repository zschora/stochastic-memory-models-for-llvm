# Exact LRU checks

`checks.json` was generated by

```powershell
python research/theory/code/lru_exact.py --out research/claims/CLM-20261107-LRUK/checks.json
```

It compares the finite-state DP with a separately written brute-force enumerator
over every distinct multiset permutation for all count vectors with at most three
labels and seven accesses, capacities 1, 2 and 3. It also checks the capacity-one
formula and enumerates every linear extension for four small labeled posets.

The script uses exact rational arithmetic (`fractions.Fraction`), so equality is
not a floating-point tolerance. This verifies the implementation on finite
instances; it does not independently prove the recurrence for all inputs.
